# بالم ستاك — Palm Stack

لعبة أربع قطع على خط واحد ضد الكمبيوتر، بتصميم ورسوم دانة التميمي.

## التشغيل على جهازك

1. فكّي ضغط الملف أولًا، ثم افتحي المجلد `PalmStack-v2`.
2. اضغطي مرتين على `START_GAME.cmd`. يستخدم Python الموجود على جهازك.
3. المتصفح يفتح تلقائيًا. اتركي نافذة التشغيل مفتوحة أثناء اللعب.

الرابط: <http://127.0.0.1:8001/index.html>

إذا لم يفتح المتصفح، افتحي الرابط يدويًا. إذا كان المنفذ مشغولًا، أغلقي نافذة تشغيل النسخة الجديدة السابقة ثم شغّليها مرة أخرى. للإيقاف: Ctrl+C داخل نافذة التشغيل. لا تفتحي `index.html` مباشرة عبر file:// لأن JavaScript Modules وWeb Worker يحتاجان HTTP.

من VS Code أو على نظام آخر: افتحي الترمينال داخل هذا المجلد وشغّلي `python serve.py` أو `python3 serve.py` بحسب اسم Python عندك. اللعبة نفسها تعمل في المتصفح، وPython هنا للتشغيل المحلي فقط.

هذه نسخة مستقلة عن مجلد ConnectFour السابق. لا تنقليها فوقه؛ تعديلاتك الدقيقة السابقة للألوان والنصوص ما زالت في نسختك القديمة. النسخة الجديدة تستخدم درجات لافندر مبدئية، ويمكن دمج اختياراتك الدقيقة عندما تشاركين الملفات المعدلة.

## الموجود الآن

- ثلاثة مستويات: سهل بعمق 2، متوسط بعمق 4، صعب بعمق 6.
- Minimax مع Alpha-Beta داخل Web Worker؛ الخوارزمية واحدة في كل المستويات.
- اللاعب يبدأ أول جولة، ثم تتبادل البداية في الجولات التالية.
- نتائج جلسة اللعب: فوز اللاعب، فوز الكمبيوتر، وتعادل.
- لوحة صدارة محلية، مع أفضل فوز واحد لكل اسم في كل فئة.
- أصوات نقر وهبوط وفوز وخسارة وتعادل مولدة برمجيًا، وزر كتم يحفظ اختيارك.
- احتفال قصير عند فوز اللاعب وتمييز خط الفوز، مع احترام إعداد تقليل الحركة.
- توقيع PNG شفاف، واسم المصممة وعبارة الحقوق.
- أماكن جاهزة لصورة الكرة الزجاجية والزخارف الجانبية، وللمقاطع الصوتية التي سنختارها لاحقًا.

لا توجد شيلة أو صور جديدة مولدة ضمن هذه الإضافة. الشكل الزجاجي المؤقت في البداية مصنوع بـCSS. الرسومات الأصلية الموجودة في assets محفوظة لإعادة استخدامها لاحقًا.

## كيف تعمل الصدارة؟

تظهر أفضل عشرة أسماء في كل فئة. الفئة تتحدد بالمستوى ومن بدأ الجولة، حتى لا تُخلط جولات مختلفة. الترتيب: أقل عدد نقلات للاعب في جولة فاز بها، ثم أقل وقت تفكير للاعب، ثم النتيجة الأقدم عند التعادل التام.

وقت التفكير يبدأ عندما تتاح نقلة اللاعب وينتهي عند اختياره عمودًا صالحًا. يستبعد حركة القطع وتفكير الكمبيوتر، ويتوقف عند فتح الصدارة أو إخفاء الصفحة. الوقت للترتيب فقط؛ لا يوجد حد زمني للخسارة.

الفوز بدون كتابة اسم لا يدخل الصدارة. الجولة الملغاة والخسارة والتعادل لا تُسجّل فيها. إعادة الجولة لا تمسح الصدارة. تغيير المستوى أو اللاعب يصفر نتائج الجلسة ويحتفظ بالصدارة.

البيانات تحفظ في localStorage لهذا المتصفح على هذا العنوان فقط. ليست لوحة مشتركة بين الأجهزة ولا حسابات مستخدمين. الاسم نفسه، بعد تجاهل المسافات الزائدة وحالة الأحرف، يُعامل كلاعب واحد؛ استخدمي ألقابًا مختلفة للمشاركين. حذف بيانات الموقع أو استخدام التصفح الخاص قد يفقد النتائج. إذا فشل الحفظ، يستمر اللعب وتظهر رسالة أن النتائج للجلسة فقط.

## ترتيب الكود

| الملف | مسؤوليته |
| --- | --- |
| `rules.js` | اللوحة، إسقاط القطع، النقلات القانونية، الفوز والتعادل |
| `ai.js` | Minimax، Alpha-Beta، تقييم الأوضاع، إحصاءات البحث |
| `ai-worker.js` | استقبال طلب البحث وإرجاع النتيجة بعيدًا عن الواجهة |
| `game.js` | الأدوار، الأحداث، الشاشات، الوقت، وربط الملفات |
| `storage.js` | تنظيف الأسماء، التحقق من البيانات، ترتيب النتائج وحفظها |
| `audio.js` | تشغيل الأصوات والكتم وتحميل الملفات الاختيارية |
| `effects.js` | إنشاء مؤثرات الفوز وتنظيفها عند الانتهاء أو الإعادة |
| `config.js` | المستويات وعبارات الفوز ومسارات الصور والأصوات |
| `index.html` | هيكل الواجهة ومناطق الوصول بلوحة المفاتيح |
| `styles.css` | الألوان والخط والتنسيق والحركة |

## إضافة الصور والأصوات لاحقًا

عدلي `MEDIA` في `config.js` بعد تجهيز الملفات:

```javascript
hero: "./assets/globe.png",
sideLeft: "./assets/palm-side.png",
sideRight: "./assets/pattern-side.png",
signature: "./assets/signature.png",
```

المسارات الفارغة لا تطلب ملفات من المتصفح. عدم وجود صورة مخصصة يبقي الشكل البديل ظاهرًا. الزخارف الجانبية خافتة وغير تفاعلية، وتختفي على الشاشات الصغيرة.

لإضافة مقطع الفوز، ضعيه في `assets/audio` ثم عدلي `AUDIO.files.win` في `config.js` مثل:

```javascript
win: "./assets/audio/win.mp3"
```

الحد الافتراضي للمقطع 8 ثوانٍ مع خفض الصوت عند النهاية. يمكن تغييره في `maxWinSeconds`. الكتم أو بدء جولة جديدة يوقف الأصوات فورًا. إذا لم يُحمّل المقطع، تعمل نغمة الفوز الافتراضية. يبدأ تفعيل الصوت بعد تفاعل المستخدم مع الصفحة، حسب سياسة المتصفح.

عبارات النتائج موجودة في `COPY`، والألوان الأساسية في `:root` داخل `styles.css`. لإضافة الكرة الزجاجية سنجهّز نسخة العرض معًا؛ لم نثبت الصورة النهائية في الواجهة بعد.

## ملاحظات لشرح الخوارزمية

المستويات تغيّر عمق البحث فقط. في كل وضع يبحث الكمبيوتر في النقلات القانونية ويستخدم التقييم عند نهاية العمق. لا يغيّر لوحة اللاعب أثناء البحث. الطلب يحمل رقمًا، وتُتجاهل النتائج القديمة بعد إعادة الجولة.

هذا بحث محدود العمق؛ لا يضمن الفوز أو أفضل نقلة على امتداد المباراة كاملة. Alpha-Beta يحافظ على قرار Minimax عند نفس العمق والتقييم مع تقليل البحث الممكن. `cutoffs` هو عدد مرات التقليم التي بقيت فيها فروع غير مفحوصة، وليس عدد الحالات التي جرى تجاوزها. `timeMs` يقيس البحث نفسه، ولا يشمل تشغيل العامل أو الرسوم أو الصوت.

## التحقق

الاختبارات داخل `tests` تعمل باستخدام Node فقط للتطوير، وليس لتشغيل اللعبة:

```text
node --test
```

تغطي منطق البحث والمستويات، ترتيب الصدارة والحفظ المعطّل والبيانات التالفة، قفل النقلات، إعادة الجولة أثناء الحركة والبحث، وإشارات الصوت والكتم. اختبارات الواجهة تستخدم محاكاة لحدود DOM وWorker؛ لا تثبت شكل العرض أو جودة الصوت على المتصفح الفعلي.

بعد التشغيل على اللابتوب: جرّبي كل مستوى، افتحي الصدارة أثناء الجولة، أعيدي الجولة أثناء تفكير الكمبيوتر، اختبري زر الكتم، ثم أعيدي تحميل الصفحة للتأكد من استمرار النتائج. تجربة المتصفح الفعلية ضرورية قبل العرض.
