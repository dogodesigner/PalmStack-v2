Custom audio is optional. The game already has synthesized sounds.

Place the selected audio files in this folder, then set their paths in
AUDIO.files in config.js. Supported event names:
click, drop, win, lose, draw.

Example:
win: "./assets/audio/win.mp3"

The win clip is limited to 8 seconds by default. New round and mute stop it.
No song or external audio recording is included in this version.
